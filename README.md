# Go Projects

A collection of Go projects demonstrating various concepts including concurrency, data persistence, in-memory storage, and CLI applications.

## Projects

| Project | Description |
|---|---|
| [In-Memory-Store](./In-Memory-Store) | Thread-safe in-memory key-value store with TTL support and automatic cleanup |
| [bank-account](./bank-account) | CLI-based bank account management system with deposit, withdrawal, and account operations |
| [go-concurrency](./go-concurrency) | Concurrency examples — DNS resolver with worker pools and concurrent URL fetcher |
| [persistent-kv-new](./persistent-kv-new) | Persistent key-value store with Write-Ahead Log (WAL) and HTTP API |
| [task-manager](./task-manager) | CLI task manager with JSON file-based persistence |
